React로 웹 화면을 만드는 프론트엔드 개발자입니다.

게임 UI와 홈페이지를 만들면서 프론트엔드에 관심을 갖게 됐고, 실무에서는 React + TypeScript 기반 업무 시스템의 화면 구현과 API 연동을 맡고 있습니다.

보기 좋은 화면보다 조작했을 때 예상대로 동작하는 화면, 그리고 다른 사람이 읽고 고치기 쉬운 코드를 우선합니다.
